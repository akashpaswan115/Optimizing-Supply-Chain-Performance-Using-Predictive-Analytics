## 📦 Supply Chain Analytics: Inventory Optimization & Risk Analysis

This project explores a real-world supply chain dataset to uncover insights into sales performance, profitability, inventory efficiency, and delivery risks. By applying statistical analysis and predictive modeling, the project identifies opportunities to optimize inventory through Economic Order Quantity (EOQ), Reorder Point (ROP), and basic demand forecasting.

### 🔍 Objectives

* Analyze and visualize key supply chain metrics including Sales, Profit, and Delivery Risk
* Detect and address multicollinearity among features to improve model reliability
* Calculate EOQ and ROP to optimize inventory and reduce holding and ordering costs
* Identify high-risk cities and products with late delivery trends or fraud-like behavior
* Provide actionable insights using clean visualizations and demand estimates

### ⚙️ Key Features

* 📊 **Exploratory Data Analysis (EDA)**: Detailed analysis of 180,000+ order records across multiple features
* 📦 **EOQ & ROP Modeling**: Applied classical inventory models using average demand, cost assumptions, and lead time
* 🧮 **Feature Engineering**: Created new features, cleaned missing data, and removed multicollinearity
* 🌍 **Geo-Visual Insights**: Mapped late delivery risk and fraud-prone cities with interactive plots
* 📈 **Demand Forecasting**: Estimated average demand per product category to inform restocking decisions

### 🛠️ Tools & Technologies

* Python, Pandas, NumPy, Scikit Learn
* Seaborn, Matplotlib, Plotly
* Jupyter Notebook
* Supply Chain Management Concepts (EOQ, ROP, Demand Estimation)
